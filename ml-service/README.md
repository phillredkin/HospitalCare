# HospitalCare ML service

Predicts the risk that a diabetic patient is readmitted to hospital within 30 days of discharge
and explains which fields raise the risk. Exposed as a FastAPI service for the C# backend.

## Layout

```
app/            FastAPI service (main.py) and request/response schemas (schemas.py)
readmission/    feature engineering, input domain checks, prediction explanations
artifacts/      trained model + metadata (loaded by the service, committed to git)
reports/        evaluation plots (ROC, precision-recall, calibration, feature importance)
train.py        trains the model and writes artifacts/ and reports/
predict.py      local prediction example on example_input.json
data/           training dataset (not in git)
```

## API

Full schema: [`docs/api/openapi.json`](../docs/api/openapi.json), or `http://localhost:8000/docs` when running.

| Endpoint | Description |
|---|---|
| `POST /predict` | Risk for one hospitalization: probability, risk level, top factors |
| `GET /health` | Service status and model version |
| `GET /model-info` | Risk thresholds, supported value ranges and codes, test metrics |

`POST /predict` responses:
- `200`, `status: "ok"` - prediction made.
- `200`, `status: "unsupported"` - valid input outside the training data range (e.g. `time_in_hospital` > 14,
  patient expired); `probability` is `null`, see `reasons`.
- `422` - invalid input (wrong type, negative number, missing required field).

`request_id` (UUID) is sent by the caller and returned unchanged; `prediction_id` (UUID) is generated by the service.

## Run locally

```
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-train.txt
.venv\Scripts\python -m uvicorn app.main:app --port 8000
```

Or with Docker from the repository root: `docker compose up ml-service`.

## Retrain

1. Download the [Diabetes 130-US Hospitals dataset](https://archive.ics.uci.edu/dataset/296/diabetes+130-us+hospitals+for+years+1999-2008)
   and put `diabetic_data.csv` into `data/`.
2. `.venv\Scripts\python train.py` (takes a few minutes).

The service loads the model with pickle, so `scikit-learn` in `requirements.txt` and the Python version in the
`Dockerfile` must match the training environment.

## Model

HistGradientBoosting on ~99k encounters, split by patient (80% train / 20% test).
Test ROC-AUC 0.68; the `high` risk group (6% of patients) is readmitted in 33% of cases vs 11% on average.
Details in `artifacts/model_meta.json`.
